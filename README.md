# Twilight — «Թռիչք դեպի դիցաբանության խորքերը»

Մրցութային նախագիծ՝ երեք խաղ հայկական դիցաբանության թեմայով (Unreal Engine 5.8)։

- **Վահագն. Վիշապաքաղ** — թռիչքային էքշն
- **Հայկ. Նետ** — նետաձգության մենամարտ
- **Արալեզ** — մրցավազք դեպի ստորերկրյա աշխարհ

Պլանը՝ `docs/PLAN_hy.md`, քայլերի մատյանը՝ `docs/SETUP_LOG.md`։
