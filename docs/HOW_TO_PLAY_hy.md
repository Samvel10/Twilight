# ԾԻՐԱՆԻ — ինչպես գործարկել և խաղալ

«Թռիչք դեպի դիցաբանության խորքերը» մրցույթի նախագիծը՝ երեք խաղ հայկական դիցաբանության հիման վրա (Unreal Engine 5.8)։

## Գործարկում

Տերմինալում.

```bash
/var/www/html/Twilight/Game/Tools/play.sh            # գլխավոր մենյու (ԾԻՐԱՆԻ), ամբողջ էկրան
/var/www/html/Twilight/Game/Tools/play.sh L_Vahagn   # անմիջապես Վահագն
/var/www/html/Twilight/Game/Tools/play.sh L_Hayk     # անմիջապես Հայկ
/var/www/html/Twilight/Game/Tools/play.sh L_Aralez   # անմիջապես Արալեզ
```

- `play.sh`-ը գործարկում է պատրաստի **Shipping փաթեթը** (`/var/www/html/Twilight/Build/Linux/Twilight.sh`, 1.7 ԳԲ, Unreal Editor պետք չէ)։ Եթե փաթեթը չկա, օգտագործում է editor-ը `-game` ռեժիմում։ Editor-ը ստիպողաբար ընտրելու համար՝ `TW_EDITOR=1 play.sh ...`։
- Փաթեթն ուղղակի գործարկելու համար՝ `Build/Linux/Twilight.sh -TwMap=L_Vahagn`։ Shipping-ը հրամանային տողի քարտեզն անտեսում է, ուստի գլուխն ընտրվում է `-TwMap=` դրոշով։
- `play.sh`-ը միացնում է նոութբուքի `performance` ռեժիմը (առանց դրա GPU-ն դանդաղում է)։
- Նոութբուքը պահիր հոսանքին միացված։
- Առաջին գործարկումը կարող է մի փոքր ավելի երկար տևել (shader-ների քեշ)։ Ներկայացումից առաջ մեկ անգամ խաղա երեք գլուխներն էլ։
- Պատուհանով ռեժիմի համար. `play.sh L_Vahagn -windowed -ResX=1600 -ResY=900`
- Խաղից դուրս գալու համար՝ Esc → մենյու → «ԵԼՔ»։

## Գլուխ I — ՎԱՀԱԳՆ. ՎԻՇԱՊԱՔԱՂ
Վահագնը ծնվում է կարմիր եղեգից և պաշտպանում է Հայկական լեռնաշխարհը։ Գործողությունը Սևանա լճի վրա է՝ Գեղամա լեռների (Աժդահակի) ֆոնին, իրական ռելիեֆով։ Օձանման վիշապները բարձրանում են լճից երեք ալիքով, հետո արթնանում է Մեծ վիշապը, և մայրամուտը դառնում է բոսորագույն փոթորիկ։ Հաղթանակից հետո երկնքում բացվում է Հարդագողի ճանապարհը (Ծիր Կաթին)։ Ժամանակը՝ 8 րոպե։

| Կառավարում | Գործողություն |
|---|---|
| Մկնիկ | Նշանառություն և ուղղություն |
| W A S D | Թռիչք |
| Space / Ctrl | Վեր / վար |
| Shift | Արագացում |
| Ձախ կոճակ | Կրակե գնդակներ |
| Աջ կոճակ (պահել, բաց թողնել) | Կայծակ ամպերից. խոցում է վիշապին և շղթայով անցնում ևս երկուսին (առասպելում Վահագնը վիշապներին խոցում է կայծակով) |
| Q | Արևի պոռթկում (երբ գոտին լցված է) |
| Alt (կամ մկնիկի միջին կոճակ) + մկնիկ | Տեսախցիկը 360° պտտվում է հերոսի շուրջը |
| F | Դիմացի տեսք (միացնել/անջատել) |
| R | Արագ 360° կինեմատոգրաֆիկ պտույտ |
| Esc | Դադար |

Խորհուրդներ. գլխին հասցված հարվածը կրկնակի վնաս է տալիս։ Սպանված վիշապներից մնացած կրակե գնդիկները բուժում են և լցնում Արևի պոռթկումը։ Կրակե շնչից խուսափիր կողք թռչելով։

## Գլուխ II — ՀԱՅԿ. ՆԵՏԻ ԹՌԻՉՔ
Ճակատամարտ Վանա լճի արևելյան ափին (իրական ռելիեֆ)։ Ռոբոտի դեմ ռեժիմում Բելը կանգնած է բլրի վրա՝ վահանակիր նետաձիգների շարքի հետևում. քանի դեռ շարքը կանգուն է, նրա երկաթե զրահը նետ չի ընդունում («վահանների պատ»)։ Խոցիր պահակներին մեկ առ մեկ (նրանք էլ են կրակում քեզ վրա)։ Երբ մնում է մեկ պահակ, գալիս է **վճռական պահը**. եռաթև նետը պատրաստ է, և պետք է այն ուղղել Բելի կրծքին։ Բելի մահից հետո նրա զորքը փախչում է։ Երկու խաղացողի ռեժիմը դասական մենամարտ է։ Կա գիշերային աշխարհ (Մասիսի ստորոտ)։

| Կառավարում | Գործողություն |
|---|---|
| Մկնիկ / WASD | Նշանառություն |
| Ձախ կոճակ (պահել) | Լարել աղեղը, բաց թողնել՝ կրակել |
| Աջ կոճակ / Q | Եռաթև նետ (դանդաղեցված, ուղղորդվող, ×1.8 վնաս) |
| Մկնիկ թռիչքի ժամանակ | Եռաթև նետի ուղղորդում |

Քամին փոխվում է ամեն հերթ։ Երկու անընդմեջ դիպուկ հարվածը տալիս է նոր եռաթև նետ (երկու խաղացողի ռեժիմում)։ Վահանները կանգնեցնում են նետերը և կոտրվում։

## Գլուխ III — ԱՐԱԼԵԶ. ԱՐԱՅԻ ԴԱՇՏԸ
Արա Գեղեցիկն ընկել է Շամիրամի զորքի դեմ մարտում՝ Արարատյան դաշտում (իրական ռելիեֆ, հարավում՝ Մասիսը)։ Մայրամուտին դու՝ Արալեզը (թևավոր շուն), երկու քույր-Արալեզների հետ իջնում ես ամպերից մարտադաշտ։ Գտիր ընկած քաջերին (էկրանի նշիչը ցույց է տալիս մոտակային), իջիր նրանց մոտ, դանդաղիր և մնա մի քանի վայրկյան, որ լիզելով բուժես վերքերը. քաջը ոտքի է կանգնում։ 8 քաջից հետո Արան «բացվում է». թռիր դաշտի կենտրոն և կենդանացրու նրան, մինչև արևը մայր մտնի (3:30)։ Շամիրամի նիզակավորները խոցում են ցածր թռչող Արալեզին, իսկ ոռնոցը նրանց հետ է նետում։ Եթե չհասցնես, Շամիրամը Արայի հանդերձը կհագցնի իր սիրեկաններից մեկին և կխաբի ժողովրդին։

| Կառավարում | Գործողություն |
|---|---|
| Մկնիկ | Ուղղություն |
| W A S D, Space / Ctrl | Թռիչք, վեր / վար |
| Shift | Պոռթկում |
| Q / Աջ կոճակ | Ոռնոց. հետ է նետում նիզակավորներին |
| Alt / մկնիկի միջին կոճակ (պահել) + մկնիկ | Ազատ 360° տեսախցիկ |
| F | Տեսախցիկը դիմացից |
| R | Արագ 360° պտույտ |

## Գլխավոր մենյու — ԾԻՐԱՆԻ
Երեք գլուխ և **Դիցարան**. Արամազդ, Անահիտ, Վահագն, Աստղիկ, Տիր, վիշապներ, Հայկ, Բել, Նավասարդ, Արա Գեղեցիկ, Արալեզներ՝ հունական զուգահեռներով։

## Տեխնիկական
- Iris Xe-ի վրա չափված Shipping փաթեթով (performance ռեժիմ, 1600×900). Վահագն՝ միջինը ~104 FPS (p99 71), Հայկ՝ ~91 FPS, Արալեզ՝ ~104 FPS։
- Ամբողջ աշխարհը, էֆեկտները, նյութերը, ձայներն ու երաժշտությունը ստեղծված են կոդով (առանց վճարովի ծառայությունների)։
