# ԾԻՐԱՆԻ — կարգավիճակ, 2026-10-19 առավոտ

## Ինչ է պատրաստ
- **Երեք ամբողջական խաղ**՝ մեկ գլխավոր մենյուով (ԾԻՐԱՆԻ) և Դիցարանով.
  - **Վահագն. Վիշապաքաղ.** ծննդի տեսարան, 3 ալիք, Մեծ վիշապ, ~4–8 րոպե։ Մեծ վիշապի հետ աշխարհը փոխվում է բոսորագույն փոթորկի՝ կայծակներով, իսկ հաղթանակից հետո ծովը խաղաղվում է։
  - **Հայկ. Նետի թռիչք.** մենամարտ Բելի (ռոբոտ, 3 դժվարություն) կամ ընկերոջ դեմ։ Երկու աշխարհ կա՝ Հայոց ձոր (մայրամուտ) և Մասիսի ստորոտ (լուսնային գիշեր, աստղեր)։
  - **Արալեզ. Հոգու վերադարձը.** մրցավազք 3 ռոբոտի դեմ՝ քարանձավ → ստորերկրյա գետ → անդունդ → Արայի դարպաս։
- **Linux Shipping փաթեթ.** `Build/Linux/Twilight.sh` (1.7 ԳԲ, Unreal Editor պետք չէ)։
- **Արագություն (Iris Xe, փաթեթ, 1600×900).** Վահագն ~112 FPS, Հայկ ~89, Արալեզ ~105։

## Ինչպես գործարկել
```bash
/var/www/html/Twilight/Game/Tools/play.sh            # մենյու, ամբողջ էկրան
/var/www/html/Twilight/Game/Tools/play.sh L_Vahagn   # (L_Hayk, L_Aralez)
```
Մանրամասները՝ `docs/HOW_TO_PLAY_hy.md`։

## Ինչ փորձարկել
1. Մենյու → Վահագն → ԽԱՂԱԼ։ Թռիր (WASD, մկնիկ), կրակիր (ձախ կոճակ), լիցքավորիր (աջ կոճակ), Q (երբ գոտին լցվի), Shift։
2. Հասիր Մեծ վիշապին (~3 րոպե)՝ փոթորիկ և կայծակներ։
3. Հայկ → «ԸՆԴԴԵՄ ԲԵԼԻ». պահիր ձախ կոճակը (լարում), բաց թող (կրակ)։ Աջ կոճակ / Q՝ եռաթև նետ։ Փորձիր նաև «ԱՇԽԱՐՀ»-ը փոխել գիշերայինի։
4. Արալեզ → «ՍԿՍԵԼ ՄՐՑԱՎԱԶՔԸ». Shift՝ պոռթկում, Q՝ ոռնոց։
5. Esc՝ դադար ամեն խաղում։

## Գիշերվա ընթացքում շտկվածը (կարճ)
- Ծովը իրական ջրի տեսք ունի (կետավոր նախշը վերացավ), իսկ կրակե գնդերն ու բռնկումները այլևս սպիտակ սկավառակներ չեն։
- Հայկի լուրջ բագ. Բելն ամեն հարվածից «փլվում» էր (անիմացիայի սխալ), սա շտկված է։
- Վահագնը թռչող դյուցազնի կեցվածք ունի (ոչ թե «ջրի վրա կանգնած»), իսկ տեսախցիկն ամուր հետևում է։
- Shipping փաթեթում վարորդի նախազգուշացման պատուհանն անջատված է, գլխի ընտրությունն աշխատում է, իսկ FPS-ը 37-ից դարձավ 112։
- Ձայնի կտրվելը (clipping) վերացված է։
- Հայերեն տեքստերի ուղղումներ (ը/ն հոդը ձայնավորից առաջ, 1-ին/2-րդ)։
- Chaos թեստեր (պատահական սեղմումներ 2 րոպե ամեն խաղում)՝ վթարներ և կախվածություններ չկան։

## Հայտնի սահմանափակումներ
- Կերպարները Unreal-ի ստանդարտ մանեկենն են՝ կրակե/ոսկե նյութով (սեփական 3D մոդելներ չկան)։
- Համակարգի ձայնը 10% է. ներկայացման ժամանակ բարձրացրու։
- Առաջին գործարկումը մի փոքր երկար է (shader cache)։ Ներկայացումից առաջ մեկ անգամ խաղա երեք գլուխներն էլ։
