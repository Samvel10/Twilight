# Twilight մրցույթ — պլան (թարմացված 2026-10-18, 21:00)

Թեմա՝ «Թռիչք դեպի դիցաբանության խորքերը»։ **Ներկայացում՝ 2026-10-22։**
Մասնակից՝ 1 հոգի։ AI-ն թույլատրված է։ Շարժիչ՝ **Unreal Engine 5.8.2** (Linux)։
Ներկայացումը՝ օգտատիրոջ նոութբուքից (Intel Iris Xe) → խաղը ՊԵՏՔ Է սահուն աշխատի այստեղ։

## Ձևաչափ
Մեկ հավելված՝ գլխավոր մենյու + 3 խաղ։ Ամեն խաղ՝ 5–10 րոպեանոց մրցախաղ (match),
1–3 աշխարհ (քարտեզ), ռոբոտներ (bots), հնարավորության դեպքում՝ 2 խաղացող նույն համակարգչով։
Վերջում՝ հստակ հաղթանակ կամ պարտություն, արդյունքների էկրան, «Կրկին խաղալ»։

## Խաղեր
### 1. «Վահագն. Վիշապաքաղ» — 10-19
- Ժանր՝ 3D թռիչքային էքշն (third-person)։
- Աշխարհներ՝ Ծիրանի ծով (մայրամուտ), Արագածի լեռներ (վիշապաքարեր)։
- Մրցախաղ՝ 8 րոպե։ Վիշապների ալիքներ → Մեծ վիշապ-բոս։ Հաղթանակ՝ բոսը սպանված է։ Պարտություն՝ կյանքը 0 է կամ ժամանակը սպառվեց։
- Կառավարում՝ թռիչք (WASD + մկնիկ), արագացում (Shift), կրակե գնդակ (ձախ կոճակ), կրակե պոռթկում (Q, լիցքավորվող)։
- Ռոբոտներ՝ վիշապներ (հետապնդում, պտույտ, կրակ)։

### 2. «Հայկ. Նետ» — 10-20
- Ժանր՝ 3D նետաձգության մենամարտ (հերթափոխով)։
- Աշխարհներ՝ Հայոց ձոր, Մասիսի ստորոտ (գիշեր)։
- Ռեժիմներ՝ ընդդեմ ռոբոտի (3 բարդություն) կամ 2 խաղացող մեկ համակարգչով։
- Մեխանիկա՝ ուժ + անկյուն + քամի, վահաններ/ծածկույթ։ Հատուկ հարված՝ «Եռաթև նետ»՝ slow-motion, տեսախցիկը թռչում է նետի հետ։
- Մրցախաղ՝ 5–8 րոպե, ով առաջինը կյանքը 0-ի հասցնի։

### 3. «Արալեզ» — 10-21
- Ժանր՝ մրցավազք + հավաքում, իջնում դեպի ստորերկրյա աշխարհ։
- Աշխարհներ՝ Քարանձավ → Ստորերկրյա գետ → Անդունդ։
- Մրցախաղ՝ 7 րոպե։ Խաղացողը + 3 ռոբոտ-Արալեզ հավաքում են Արայի հոգու լույսերը, ստվերները հետապնդում են։
- Հաղթանակ՝ ամենաշատ լույսերը → Արայի կենդանացման տեսարան։

## Ընդհանուր հիմք (կառուցվում է 10-19-ին՝ Վահագնի հետ)
- Գլխավոր մենյու (հայերեն), խաղի ընտրություն, կարգավորումներ (որակի նախադրումներ)
- Մրցախաղի ցիկլ՝ ժամաչափ, կյանք, հաղթանակ/պարտություն, արդյունքներ, կրկնում
- Ձայնի կառավարում, Enhanced Input (ստեղնաշար + gamepad), ռոբոտների հիմք
- Դիցարան՝ քարտեր, որոնք բացվում են խաղերում

## Գրաֆիկա և ձայն (առանց կրեդիտների)
- Unreal-ի ներքին միջոցներ՝ ThirdPerson կերպար (անիմացիաներով), StarterContent, Water, PCG, Niagara, procedural լանդշաֆտ (numpy heightmap)։
- Վահագն՝ կերպար՝ կրակե նյութով + Niagara կրակ։ Վիշապներ՝ կոդով կառուցված օձանման մարմին։ Արալեզ՝ լուսե ոգի։
- Կոնցեպտ-արտ՝ կոդով (HTML canvas → Chrome screenshot)։
- Ձայն՝ CC0 գրադարաններ (օր.՝ Kenney) + Python-ով սինթեզված ֆոնային երաժշտություն։
- Հետագայում, եթե կրեդիտներ լինեն՝ Higgsfield-ով փոխարինում։

## Որակի դարպաս (ամեն խաղ, նախքան «պատրաստ» ասելը)
1. Արկը դուրս է գալիս ձեռքից և թռչում է **հենց նշանառության կետին** (crosshair → հարվածի կետ)։
2. Կերպարը չի ընկնում աշխարհից, չի թռչում սահմաններից դուրս (փափուկ սահմաններ)։
3. Տեսախցիկը չի մտնում պատերի մեջ։
4. Հաղթանակը և պարտությունը հասանելի են, «Կրկին»-ը աշխատում է։
5. ≥ 45 FPS Iris Xe-ի վրա ընտրված որակով։
6. 3 ամբողջական խաղ առանց crash-ի։
7. Ստուգում՝ ես գործարկում եմ խաղը, վերցնում եմ էկրանի կադրեր (ffmpeg) և դիտում եմ դրանք։
